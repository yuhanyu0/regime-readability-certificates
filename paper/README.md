# Manuscript provenance

Public artifact v0.1 is anchored to the working manuscript **RRC_Manuscript_v3_7**.

The manuscript PDF and TeX source are provenance-locked in `SOURCE_DOCUMENTS.json` but are not duplicated in this curated GitHub release. The repository is intended to expose the certificate grammar, executable synthetic detector audit, compact frozen result summaries, and the recovered market-audit code without pretending that the empirical market pipeline is fully self-contained.

This is a working-manuscript artifact, not a peer-reviewed publication claim.
