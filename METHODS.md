# Methods snapshot

## Claim descent

Given a measurement protocol `pi`, latent states are grouped into exact observational equivalence classes or a declared observational partition. A proposed state label is readable only to the extent that it is approximately constant within those cells. If states are indistinguishable to the protocol but the label separates them, the claim does not descend through the protocol representation.

## Readability transition

The controlled module fixes a binary latent distinction and varies the observation-compression protocol. The released alpha sweep records protocol strength, descent defect, readability order parameter, AUC, GMM evidence, guard status, and RRC fields. The declared certificate threshold is an audit threshold, not a physical critical point.

## Detector benchmark

Five controlled worlds are evaluated by GMM, a compact two-state Gaussian HMM, a change-point detector, and a threshold detector. RRC then audits the detector output using support and protocol information known in the synthetic worlds.

## Market readout audit

ETF15 rolling correlation matrices use window 90 and leading-mode localization by IPR. The full fixed-band atlas sweeps band width/center, stride, minimum component size, and minimum component fraction. The strict headline slice uses stride 1, minimum component size 80, and minimum component fraction 0.10.

Market audit layers are reported separately:

- descriptive fixed-band readability atlas;
- discovery/confirmation time splits;
- primary-GMM moving-block bootstrap for selected bands;
- restricted primary-GMM max-null audit;
- multi-null sensitivity across iid permutation, circular shift, and moving-block IPR nulls;
- focused high-replicate follow-up for the strongest observed candidates.

Every market layer keeps `support_scope = not_asserted`.
