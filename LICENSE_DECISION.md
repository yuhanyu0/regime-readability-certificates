# License decision

No repository-wide open-source license is attached to v0.1.

The release combines original audit code, compact frozen empirical-derived summaries, curated summary figures, and provenance references to a working manuscript and larger source assets. Default copyright therefore applies unless a file states otherwise.

A later software-oriented release can make an explicit code-license decision without retroactively implying that every manuscript/data artifact referenced by v0.1 was distributed under that license.
